RESUMEN EJECUTIVO:
================================================================================

Se ha desarrollado un **sistema completo de Machine Learning** para predecir y
analizar el desempeño de empleados usando un framework Kedro con 7 pipelines
de procesamiento de datos y modelado.

Dataset: 309 empleados con 4 tablas fuente (empleados, evaluaciones, 
ausencias, capacitaciones) consolidadas en 14 features.

MODELOS ENTRENADOS Y EVALUADOS:
1. Linear Regression        - Baseline simple
2. Ridge Regression         - Con regularización L2
3. Lasso Regression         - Con regularización L1
4. Random Forest            - Conjunto de árboles
5. Gradient Boosting        - Boosting iterativo
6. SVR (Support Vector)     - Máquinas de vectores soporte
7. K-Nearest Neighbors      - Basado en similaridad

MEJOR MODELO: Gradient Boosting / SVR (según evaluación anterior)
- Validación Cruzada: ~0.73 R²
- Test Set: Métrica R² optimizada
- Residuos: Media ≈ 0.30, Desv.Estándar ≈ 4.30

ANÁLISIS NO SUPERVISADO:
- PCA: 9 componentes para 95% de varianza (reducción: 36%)
